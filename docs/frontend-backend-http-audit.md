# Auditoria HTTP frontend ↔ backend

Esta matriz é o inventário das chamadas autenticadas do frontend. Todas passam por `services/api.ts`, que acrescenta o Bearer token, renova a sessão uma única vez e repete a chamada após `401`. Endpoints com `:id` representam parâmetros dinâmicos. As rotas de health/version são Route Handlers públicos do Next.js.

## Conclusões aplicadas

- Os endpoints frontend de analytics que retornavam `404` agora têm contratos dedicados e escopo por organização.
- Configurações e relatórios deixaram de ser controllers vazios; seus módulos agora registram Prisma, autenticação, providers e services reais.
- O schema Prisma voltou a declarar as três tabelas já criadas pela migration enterprise, eliminando divergência entre migration, client gerado e DTOs de configuração.
- A URL antiga de teste de conta (`test-connection`) foi alinhada à rota backend `/test`.
- O fallback RBAC agora concede explicitamente criação e atualização de templates, além da permissão agregada legada.
